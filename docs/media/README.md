# Promotional assets

All imagery uses fictional demo content. The source layout, copy, and reproducible render command live in [`marketing/`](../../marketing/README.md).

| Asset | Format | Intended use |
| --- | --- | --- |
| `kept-promo.mp4` | 1920×1080, H.264, 30 fps, 14.3 s, silent | Product teaser, launch posts, website video |
| `kept-promo-poster.jpg` | 1920×1080 | Video poster and thumbnail |
| `kept-hero.png` | 1920×1080 | README/website hero |
| `kept-og.png` | 1280×640 | GitHub/social link preview |
| `kept-social-square.png` | 1080×1080 | Square social post |
| `kept-social-story.png` | 1080×1920 | Story/Reel cover |

The video is intentionally silent for muted autoplay and easy soundtrack replacement.
